# 首页样式选择

打开 [homepage-options.html](homepage-options.html)。页面无需网络或外部素材，可以直接在浏览器查看。

已选择 **A · 留白馆览**。原生首页实现三个实际馆内指标、当前预约和预约记录入口，并按新增要求自动读取当天每个区域的座位使用情况。

| 方案 | 视觉方向 | 适合的选择理由 |
| --- | --- | --- |
| A · 留白馆览 | 白色概况卡、突出空闲席位、清晰的预约与快捷入口 | 延续现有留白界面，将当前馆内数据直接放在首页。 |
| B · 书页专注 | 随主题变色的书本线稿、浅色主视觉、融合馆内数据 | 推荐。更强调图书馆的视觉特点，主题色变化更明显。 |
| C · 馆图导航 | 区域示意卡、醒目的空闲席位、主要入口改为布局选座 | 适合以位置为中心找座位；区域统计需要额外的数据加载。 |

预览提供全部六种主题色，包括与应用一致的奶龙黄 `#FFCE32`。点击方案的选择按钮后，页面底部会生成可复制的中文选择文字。数据状态可以切换为最新同步、上次数据和尚未同步；未同步数值显示为 `—`，不会推断“没有预约”。

所有数值、日期、区域、公告和预约都明确作为演示内容；页面不会请求图书馆服务器。全馆概况使用已有 `LibraryOverview.available`、`inUse`、`awaitingSignIn`，当前预约对应 `LibraryHubState.currentStatus` 与 `currentDetails`。颜色、文字与布局可以直接转写为 Compose 组件。

原生 A 方案新增“各区域座位”：自动发现当天的场馆、楼层和区域，逐一读取真实布局，展示区域总席数与空闲、使用中、已预约、暂离等状态。使用中、已预约和暂离组成“已确认占用”；仅限现场与未知状态单独显示。每项带读取日期、更新时间与旧数据标记，尚未读取、读取失败或额外验证不会显示为零。该区的数据通过独立接口取得，不从全馆概况推算。HTML 中的区域数字仍为样式演示。C 的区域图仅作视觉示意，实际选座继续使用服务器的真实坐标。

后续界面调整已移除首页重复的选座与收藏入口；点击区域卡片直接打开该区域座位布局，区域仍默认展开并支持手动收起。HTML 保留最初选型的演示，不作为最终每个按钮的清单。
