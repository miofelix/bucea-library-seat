查看预览数据与实现说明

所有数字、日期、区域名称、预约和公告均为排版演示，没有连接图书馆服务。全馆概况只使用现有 LibraryOverview 的 available（空闲）、inUse（使用中）、awaitingSignIn（等待签到），不假设馆内人数、开放时长、全馆总座位或空闲率等额外接口字段。

“已查看区域”的空闲 / 总席数可从 NativeRoomLayout.cells 中 seat.available 和非空 seat 的数量推导，但需要单独读取对应区域的布局，不能从全馆概况取得。实施时仅展示成功读取的区域及对应日期，未加载、额外验证和网络异常需要保留明确状态。这里的两个区域只是示例，不能代表全馆。

“上次数据”保留上次全馆数值并明确标记；“尚未同步”使用 — 占位，不伪造为 0。当前预约来自 LibraryHubState.currentStatus / currentDetails；尚未同步状态不推断“无预约”。图标沿用主题色，奶龙黄使用深色文字与图标保证对比度。A 延续 docs/UI_DESIGN.md 的留白界面；B 和 C 提供更明显的视觉方向，选择后同步更新界面规范。
