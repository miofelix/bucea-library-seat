# APK 体积与优化取舍

1.0.0 采用「通用包＋四种架构包」，并对原生库进行无损压缩。
普通近年安卓手机优先安装 **ARM64**；不确定架构时使用通用包。
文件大小均按 **1 MB = 1,000,000 字节**计算，与部分系统使用的 MiB 不同。

## 安装包实际大小

| 安装包 | 适用设备 | 字节数 | 大小 |
|---|---|---:|---:|
| `北建大图书馆选座-v1.0.0.apk` | 通用，包含四种架构 | 55,527,607 | 55.53 MB |
| `北建大图书馆选座-v1.0.0-arm64-v8a.apk` | ARM64，近年安卓手机推荐 | 33,811,128 | 33.81 MB |
| `北建大图书馆选座-v1.0.0-armeabi-v7a.apk` | ARM32，部分较旧设备 | 33,245,934 | 33.25 MB |
| `北建大图书馆选座-v1.0.0-x86.apk` | 32 位 Intel/部分模拟器 | 35,066,066 | 35.07 MB |
| `北建大图书馆选座-v1.0.0-x86_64.apk` | 64 位 Intel/部分模拟器 | 35,053,979 | 35.05 MB |

表中数据来自本地 1.0.0 发布构建；最终附件以 Release 的 `SHA256SUMS` 为准。
架构包保留相同功能、模型和数据格式，区别是仅包含对应处理器的原生库。

## 原来的通用包为什么达到 102.56 MB

| 内容 | 在原安装包中占用 | 占比 |
|---|---:|---:|
| ONNX Runtime 等原生库，包含四种架构 | 75.24 MB | 73.4% |
| 验证码文字检测模型 | 18.68 MB | 18.2% |
| 验证码文字识别模型 | 6.83 MB | 6.7% |
| 应用与依赖的 DEX 代码 | 1.45 MB | 1.4% |
| 资源、元数据、签名和 ZIP 结构等 | 0.37 MB | 0.4% |

主要来源是本地验证码识别运行时与模型。Release 已启用 R8 代码压缩和资源缩减；
继续删减界面、图标或普通业务代码的收益很小。
大型 `libonnxruntime.so` 已不含调试符号，不能再靠剥离调试信息缩减数十 MB。

## 当前方案如何平衡下载、存储和性能

按架构拆包后，ARM64 原本约 **45.56 MB**；压缩原生库后降到 **33.81 MB**，
相对原通用包减少约 **67%**。通用包也从 102.56 MB 降到 55.53 MB，减少约 **46%**。

压缩使用 Android 支持的原生库安装机制：安装或更新时解压所需架构，
运行时加载解压后的原始文件。每次启动、每次识别都不需要重复解压。
逐项比较确认，十二个原生库和两个模型的内容均与优化前完全一致，模型精度不变。

代价是压缩包与解压后的库会同时占用空间。ARM64 的「已安装 APK＋原生库」
约为 **52.14 MB**，比不压缩的 ARM64 包约增加 **6.58 MB**，换取约 **11.74 MB** 的下载节省。
这是静态文件估算，**不等于系统设置显示的完整应用占用**；后者还包括 ART 编译产物、
账号与业务数据、缓存等。浏览器或更新器另行保留的下载文件也需单独计算。

## 还可以进一步缩小吗

识别模型 `common_old.onnx` **已经使用 INT8 量化**，包含整数卷积、整数矩阵乘法和
`DynamicQuantizeLSTM`；并非两个模型都能简单再缩小到四分之一。
检测模型 `common_det.onnx` 仍是 FP32，未来可以评估 FP16/INT8，
但必须验证定位框、文字顺序、点击坐标和不同处理器的正确率、耗时与内存。
当前四组真实验证码回归样例不足以证明新量化模型的总体识别率，因此 1.0.0 保留现有模型。

按两个模型实际使用的算子裁剪 ONNX Runtime 也有潜力，需要维护定制构建、JNI、
Microsoft 扩展算子、四种架构和 Android 页面对齐兼容性；收益需要构建后实测。
R8 无法裁掉预编译 `.so` 内部的算子，直接换成任意「mobile」运行时可能无法加载现有模型。

已实测排除收益较低的方案：提高模型 ZIP 压缩等级总共只省约 **54 KB**；
改用 XZ 只省约 **0.54 MB**，却增加解码器和加载逻辑，主机解压测试也明显更慢。
模型改成首次使用时下载可减少初次 APK 大小，但会给登录、验证增加新的网络依赖，
也不会减少实际使用后的总下载量，因而未采用。

## 复现构建

使用项目要求的 Java 17 和 Android SDK，生成通用包与四种架构包：

```sh
./gradlew -PreleaseDistributions=true :app:stageReleaseApk
```

输出目录为 `app/build/outputs/release/`。需要比较不压缩原生库的构建时：

```sh
./gradlew -PreleaseDistributions=true -PcompressNativeLibraries=false :app:stageReleaseApk
```

比较构建会重新生成同一输出目录；请先另存候选产物。实际安装与功能验收记录见
[1.0.0 ADB 验收](ADB_ACCEPTANCE_1.0.0.md)。
