本次测试版为 **0.3.6 / versionCode 11**，修复切换 Wi-Fi 后返回应用仍停留在“无法访问”状态的问题。上次图书馆连接不可达且当前没有进行中的操作时，返回应用会自动重新检查连接；连接恢复后继续恢复已保存的账号会话。

访问失败时改为提示“暂时无法访问图书馆”，说明校园链路或图书馆服务可能暂时不可用。连接校园网仍需实际能够访问图书馆服务器；本次客户端修复不能消除校园链路或服务器自身的间歇性超时。用户暂不测需要图书馆内部 Wi-Fi 的签到及后续使用操作。

本版在 Android 16 / API 36 手机上通过 **107 项独立设备测试**（18.366 秒，无跳过）和真实校园只读查询；另通过 **23 项 JVM 测试**、**38 项 Python 测试**，Debug / release / AndroidTest 构建和两种 Lint 均无错误。同签名 release 实机覆盖安装保留账号、偏好、收藏与主题。最终安装及公开更新源验证见 [0.3.6 ADB 验收](https://github.com/miofelix/bucea-library-seat/blob/main/docs/ADB_ACCEPTANCE_0.3.6.md)，服务器超时及恢复证据见 [校园访问检查记录](https://github.com/miofelix/bucea-library-seat/blob/main/docs/CAMPUS_ACCESS_DIAGNOSIS.md)。

0.3.4 起可在“设置 → 应用更新”手动检查并确认下载，再交由系统安装器安装；0.3.3 及更早用户需先手动安装。检查更新无需连接校园网。其余尚未实测的条件见 [验证记录](https://github.com/miofelix/bucea-library-seat/blob/main/docs/VALIDATION.md)。
