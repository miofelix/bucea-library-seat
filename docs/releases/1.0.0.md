正式版 **1.0.0 / versionCode 14**，提供原生选座、座位布局、收藏预约和应用更新，并集中完善界面密度、筛选交互与页面状态恢复。

- 整体界面更加紧凑：首页、选座、地图、我的、账号和设置统一收紧留白、卡片内边距与区块间距；普通字体下首页统计横向排列，账号操作在空间充足时并排显示，大字体下自动换行。
- 座位结果采用一行四个的近方形迷你卡片：绿色边框为可预约，红色边框为不可预约。点按可约座位选择时段，长按卡片收藏或取消收藏，已收藏显示星标；大字体下自动增高。
- 自选座位在同一页面连续展示全部查询结果，取消手动翻页，加载中断可从原位置继续。布局选座的列表也采用四列迷你卡片，支持筛掉不可预约座位；“地图｜列表”标签栏降至 44dp，随整页滑动移出，切换时保持高度与位置稳定，并分别保留滚动位置。
- 收藏页增加长按收藏说明；点击收藏或常用座位直接在“我的”页面选择日期和时段、确认预约。
- “选座”和“我的”采用一致的圆角分段标签，选座补充装饰标题与标语。切换底部导航后保留滚动位置与展开状态，两种选座模式各自保留筛选和浏览位置。
- “时间、电源与靠窗”及展开内容移至“座位号（可选）”上方，收紧入口、座位号输入框和“仅看可用”区域，并合并结果数量提示。
- 切换场馆时清空旧区域，显示加载状态并支持单独重试；连续加载失败保留结果并重试原请求。地图加载失败后继续重试刚才选择的区域。
- 账号编辑在页面重建后保留正确的编辑目标和备注，输入中的密码不写入界面恢复状态；窄屏和大字体下的操作布局更清晰。
- 首页馆内公告逐条显示，保留原文段落和换行，排除混入的座位统计数字。设置新增图书馆官网入口，底部署名更新为 BUCEA-LIBRARY-SEAT。
- 改善页面标题、分段标签和展开状态的无障碍提示。

安装包从本版起统一命名为 `BUCEA-Library-Seat-vx.x.x.apk`，本版通用包为 `BUCEA-Library-Seat-v1.0.0.apk`。分架构包分别为 `BUCEA-Library-Seat-v1.0.0-arm64-v8a.apk`、`BUCEA-Library-Seat-v1.0.0-armeabi-v7a.apk`、`BUCEA-Library-Seat-v1.0.0-x86.apk` 和 `BUCEA-Library-Seat-v1.0.0-x86_64.apk`。

本版同时提供通用包和四种分架构的独立 APK。通过分架构与原生库无损压缩，通用包从 102.6 MB 降至 **55.5 MB**，ARM64 包为 **33.8 MB**（相比原通用包减少约 67%）。多数现代手机建议选 `arm64-v8a`；旧款 ARM 32 位手机选 `armeabi-v7a`，Intel 设备或模拟器选对应的 `x86` / `x86_64`；不确定时选通用包。分架构包在统一名称后增加架构后缀，无需其他 split 文件即可安装。

原生库由 Android 在安装时解压一次；完整保留现有离线识别模型与功能。体积与安装占用的取舍见 [APK 大小分析](https://github.com/miofelix/bucea-library-seat/blob/main/docs/APK_SIZE.md)。

本版通过 76 项 JVM 测试、144 项独立 ADB 设备测试、2 项真实校园只读测试和 69 项发布工具测试。真机覆盖离线文字/点击验证码识别、普通及 1.6 倍字体下的整页滑动、标签栏滑出、视图切换和收藏页预约交互；未提交实际预约或座位使用操作。

使用图书馆功能仍需可访问图书馆服务器的校园网络，签到需要图书馆内部 Wi-Fi。0.3.4 起可在「设置 → 应用更新」检查、下载并交由系统安装新版。
