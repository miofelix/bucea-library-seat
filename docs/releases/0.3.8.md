此 **0.3.8 / versionCode 13** 为已验证、未发布的候选版本；最终改为直接发布 [1.0.0 正式版](1.0.0.md)。以下保留该候选版本的功能与验证记录。

- 整体界面更加紧凑：首页、选座、地图、我的、账号和设置统一收紧留白、卡片内边距与区块间距；普通字体下首页统计横向排列，账号操作在空间充足时并排显示，大字体下自动换行。
- 座位结果采用一行四个的近方形迷你卡片：绿色边框为可预约，红色边框为不可预约。点按可约座位选择时段，长按卡片收藏或取消收藏，已收藏显示星标；大字体下自动增高。
- 自选座位在同一页面连续展示全部查询结果，取消手动翻页，加载中断可从原位置继续。布局选座的列表也采用四列迷你卡片，支持筛掉不可预约座位；“地图｜列表”标签栏降至 44dp，切换时保持上方控件位置稳定，并分别保留滚动位置。
- 收藏页增加长按收藏说明；点击收藏或常用座位直接在“我的”页面选择日期和时段、确认预约。
- “选座”和“我的”采用一致的圆角分段标签，选座补充装饰标题与标语。切换底部导航后保留滚动位置与展开状态，两种选座模式各自保留筛选和浏览位置。
- “时间、电源与靠窗”及展开内容移至“座位号（可选）”上方，收紧入口、座位号输入框和“仅看可用”区域，并合并结果数量提示。
- 切换场馆时清空旧区域，显示加载状态并支持单独重试；连续加载失败保留结果并重试原请求。地图加载失败后继续重试刚才选择的区域。
- 账号编辑在页面重建后保留正确的编辑目标和备注，输入中的密码不写入界面恢复状态；窄屏和大字体下的操作布局更清晰。
- 首页馆内公告逐条显示，保留原文段落和换行，排除混入的座位统计数字。设置新增图书馆官网入口，底部署名更新为 BUCEA-LIBRARY-SEAT。
- 改善页面标题、分段标签和展开状态的无障碍提示。

安装包从本版起统一命名为 `北建大图书馆选座-vx.x.x.apk`，本版文件为 `北建大图书馆选座-v0.3.8.apk`。

本版通过 76 项 JVM 测试、144 项独立 ADB 设备测试、2 项真实校园只读测试和 48 项发布工具测试。真机覆盖普通与 1.6 倍字体下的整页滑动、视图切换和收藏页预约交互。真实区域查询读取 8 个区域、1708 个座位，未知状态为 0；未提交实际预约或座位使用操作。

使用图书馆功能仍需可访问图书馆服务器的校园网络，签到需要图书馆内部 Wi-Fi。0.3.4 起可在「设置 → 应用更新」检查、下载并交由系统安装新版。

本次更新镜像同步暂缓，请先从本 Release 下载 APK 安装。
