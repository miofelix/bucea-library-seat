本次测试版为 **0.3.8 / versionCode 13**，主要优化界面密度、筛选交互与页面状态恢复。

- 整体界面更加紧凑：首页、选座、地图、我的、账号和设置统一收紧留白、卡片内边距与区块间距；普通字体下首页统计横向排列，账号操作在空间充足时并排显示，大字体下自动换行。
- “选座”和“我的”采用一致的圆角分段标签，选座补充装饰标题与标语。切换底部导航后保留滚动位置与展开状态，两种选座模式各自保留筛选和浏览位置。
- “时间、电源与靠窗”及展开内容移至“座位号（可选）”上方，收紧入口、座位号输入框和“仅看可用”区域，并将本页数量提示合并展示。
- 切换场馆时清空旧区域，显示加载状态并支持单独重试；分页失败保留结果并重试原页面。地图加载失败后继续重试刚才选择的区域。
- 账号编辑在页面重建后保留正确的编辑目标和备注，输入中的密码不写入界面恢复状态；窄屏和大字体下的操作布局更清晰。
- 首页馆内公告逐条显示，保留原文段落和换行，排除混入的座位统计数字。设置新增图书馆官网入口，底部署名更新为 BUCEA-LIBRARY-SEAT。
- 改善页面标题、分段标签和展开状态的无障碍提示。

本版通过 75 项 JVM 测试、135 项独立 ADB 设备测试、2 项真实校园只读测试和 38 项发布工具测试。真实区域查询读取 8 个区域、1708 个座位，未知状态为 0；未提交实际预约或座位使用操作。

使用图书馆功能仍需可访问图书馆服务器的校园网络，签到需要图书馆内部 Wi-Fi。0.3.4 起可在「设置 → 应用更新」检查、下载并交由系统安装新版。

本版构建、签名、ADB 真机与公开更新验证见 [0.3.8 验收记录](https://github.com/miofelix/bucea-library-seat/blob/main/docs/ADB_ACCEPTANCE_0.3.8.md)。
