正式版 **1.0.1 / versionCode 15**，更新安装包内的应用更新地址，使用 Cloudflare R2 分发更新清单和 APK。

- 应用内检查更新与安装包下载改用 `download.miofelix.com`，无需直接访问 GitHub。官网下载也使用同一分发来源，GitHub Release 保留为备用下载。
- App 设置与官网新增开源许可入口，可查看项目的 MIT 许可证。
- 沿用原有应用签名，用于覆盖升级已安装的版本。使用旧更新地址的版本，请先从[官网](https://library.miofelix.com/#download)下载安装本版；安装后可在「设置 → 应用更新」手动检查更新。
- 继续提供通用包及 `arm64-v8a`、`armeabi-v7a`、`x86`、`x86_64` 四种独立 APK。多数现代手机建议选择 ARM64，不确定时选择通用包。

支持 Android 8.0 及以上。图书馆功能仍需可访问图书馆服务器的校园网络，签到需要连接图书馆内部 Wi-Fi；应用更新检查无需校园网。
