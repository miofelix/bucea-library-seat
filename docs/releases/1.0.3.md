正式版 **1.0.3 / versionCode 17**，改进图书馆 Wi-Fi 座位操作与预约查看。

- 修复连接图书馆 Wi-Fi 后无法签到、暂离、返回、续约和结束使用的问题；学校允许操作时隐藏重复的 Wi-Fi 提示。
- 修复续约已生效却短暂报错、显示“暂时无法同步”的问题。
- 当前预约卡片以紧凑布局显示真实座位、区域、日期、时段和状态，统一使用“我的预约”的座位信息与位置格式；首页移除重复的预约记录小卡片。
- 预约页面的当前、接下来及历史预约均可查看座位位置，自动打开对应区域地图并高亮座位；历史地图不可用时明确说明使用当前布局。
- 统一区域直达和预约定位的地图图例位置，提供“恢复布局选座”和“返回预约”入口。
