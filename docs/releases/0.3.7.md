本次测试版为 **0.3.7 / versionCode 12**，更新首页、主题与布局选座的视觉呈现。

- 新增奶龙黄 `#FFCE32`。亮黄用于主题底色和主要选座按钮，文字、边框与选择控件使用可读的深金色。
- 桌面图标随应用内六种主题颜色切换，选择在重启后保留。首次升级打开应用后同步图标；启动器刷新可能稍有延迟，Android 单色主题图标继续由系统壁纸配色决定。
- 首页采用选定的「A · 留白馆览」：直接展示空闲座位、正在使用、等待签到，标明同步状态，并保留当前预约和预约记录。未返回的数字显示待同步，不推断为零。
- 首页自动读取当天各馆舍、楼层和阅览区域的座位布局，显示每区总席数、空闲、使用中、已预约等状态及占用条。区域默认展开，可手动收起；卡片采用紧凑双列并保持同行等高。进入首页和返回前台时按两分钟缓存更新，支持手动刷新；部分查询失败或需验证时保留已读数据并明确提示。
- 选座结果改为双列卡片，同行的可用与不可用座位自然等高；点击整张可预约卡片或“可预约”即可选时间，删除独立底部按钮并减少空白。导航栏也调整为更紧凑的样式。
- 布局选座改为醒目的实色座位，使用不同颜色和文字标记区分状态；选中座位增加主题色与深色描边。座位当前状态与可预约时段分别呈现，时段以点选查询为准。
- 修复普通地图页面被误判为需要额外验证的问题，并正确识别学校的“当前已有预约”状态。验证时重新读取当前会话与学校返回的有效参数。
- 预约、取消预约、收藏和座位操作增加一次性 Toast，显示提交状态与确认结果，失败及结果不确定时保留对应说明。
- 点击首页区域卡片直接显示对应座位图，返回即回首页；设置中的 QQ 交流群支持点按打开 QQ 入群页面、长按复制群号。
- 首页及我的预约移除重复选座入口；我的预约按时间线展示各次预约的时间、位置与状态，保留查看详情及取消确认。关于页面精简 QQ 群及验证码识别说明。

最终通过 64 项 JVM 测试、125 项 ADB 设备测试及真实校园只读查询；实机读取 8 个区域、1708 个座位，“未知”状态为 0。同签名 Release 已覆盖安装验收。

构建、ADB 设备验证、签名与覆盖安装结果见 [0.3.7 验收记录](https://github.com/miofelix/bucea-library-seat/blob/main/docs/ADB_ACCEPTANCE_0.3.7.md)。首页候选样式保留在 [HTML 预览](https://github.com/miofelix/bucea-library-seat/blob/main/docs/design/homepage-options.html)。

0.3.4 起可在「设置 → 应用更新」检查并下载新版，再交由系统安装器安装。使用图书馆功能仍需可访问图书馆服务器的校园网络，签到需要图书馆内部 Wi-Fi。
