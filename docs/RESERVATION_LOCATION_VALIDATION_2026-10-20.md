# 预约信息与座位定位验证

验证设备：PKX110 / Android 16，已有账号，图书馆 Wi-Fi。所有真实服务验证只读取预约和地图，没有提交预约、签到、续约、取消或结束使用。

## 最终行为

- 首页移除“预约记录 / 随时查看”快捷小卡片。当前预约展示座位、区域、日期时段和短状态，隐藏凭证及展开字段；普通字号最多每行三个操作，大字体改为两项，保留至少 48dp 触控区域。
- 座位与位置统一来自学校“我的预约”列表 `/history?type=SEAT`。`/self` 仅提供当前状态和操作；`/view` 可补日期、时间和状态，但不会覆盖列表的座位位置。当前预约按状态与日期唯一匹配，不使用结束或取消的历史记录冒充当前预约。
- 位置文字统一显示为“图书馆2层内环区003D号”，去掉“位置：”、重复楼层、逗号和“座位号”。原始数据保留供请求与区域匹配。
- 预约页面所有记录卡（当前、接下来、历史、取消及结束使用）都有定位入口。按日期、场馆、楼层、区域和座位编号获取真实地图，保留座位状态颜色，并以双轮廓和“约”标记持续高亮目标。地图初次自动居中，查看其他座位不会移除预约高亮。
- 历史日期不再可读时，显示今天的物理布局，明确列出原预约日期与地图日期；未来日期不可用时保留错误，不改变预约日期。位置含糊时给出原因，不选择任意同名座位。
- 首页区域直达及预约定位的图例均在地图上方；“恢复布局选座”恢复日期、场馆、楼层和区域选择。“返回预约”回到来源页面。切换账号或离开待定位记录时取消旧请求。

## 验证

- Debug / Release JVM 单元测试各 139 项通过；Debug、AndroidTest 和 Release 构建通过，Debug / Release Lint 0 个 Error。
- 设备用例覆盖当前信息、普通和 1.6 倍字号、当前/未来/结束/取消记录的定位回调、缺失资料、首页入口删除、占用座高亮、图例顺序以及两种直达入口恢复布局选择。
- `LibraryFunctionsInstrumentedTest` 18 项、`LibraryHubUiInstrumentedTest` 11 项、`DashboardUiInstrumentedTest` 4 项通过；地图焦点 3 项在修正滚动测试的标题区可见性断言后全部通过，共覆盖 36 项设备用例。
- 真实服务测试 `LiveReservationMapLocationTest -e live_library true`：读取已有 003D 预约，精确匹配二层内环区及真实 seat ID；没有使用预约编号推算座位 ID。
- 实际学校楼层标签为“图书馆2层”等，区域标签为“二层内环区”等；对匹配前移除场馆前缀的逻辑加入真实结构回归。
- 真机操作确认 003D 定位、高亮、图例在地图上方，以及“恢复布局选座”重新显示日期、场馆、楼层和区域选择；首页区域直达同样确认图例和恢复入口。
