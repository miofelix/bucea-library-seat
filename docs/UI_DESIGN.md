# 留白界面

原生应用统一采用「留白」界面。简洁优先，通过排版、留白和少量主题色建立层次。

## 视觉规则

- 页面背景为中性的 `#FAFAFA`，正文 `#272729`，次要文字 `#707075`，分隔线 `#E7E7E9`。
- 主题色来自 `AppThemeColor` 与外观存储，默认建大紫 `#6C397F`，提供包含奶龙黄的六种颜色。主题切换同步桌面图标；奶龙黄使用亮黄底色、深色按钮文字和可读的深金色文本与选择控件。
- 页面横向与顶部留白统一为 16dp，主要区域相隔 12dp；通用卡片内边距 16dp、内部间距 10dp，筛选卡片及预约记录采用更紧凑的 12dp 内边距。白色卡片使用 18–24dp 圆角、细描边与零阴影。
- 无衬线页面标题 24sp / 30sp 行高，组件标题 14–18sp，正文维持 12–15sp。装饰文字与筛选标签分别使用清晰的紧凑行高，减少继承正文行高带来的空白；主要按钮至少 48dp，圆角 12dp。
- 页头装饰、标题与标语间隔为 4dp；无操作按钮的区块标题最小高度 24dp，带操作时保留 48dp。设置条目最小高度 64dp，垂直内边距 10dp；空状态和底部面板同步压缩留白。大字体时内容自然换行、增高，账号、收藏和主要操作保留 48dp 点击范围，地图拖动与缩放区域保持可用。
- 选座的高级筛选入口常规高度 36dp，“仅看可用”区域 40dp，座位号输入框 48dp；查询后的本页数量并入可用筛选的副标题，减少重复行和间距。输入框保留键盘输入、选取文本和无障碍标签，大字体下按内容自然增高。
- 底部导航采用紧凑的白色圆角容器，20dp 图标配 10sp 标签，选中项使用浅主题色背景，单项触控高度至少 48dp；系统安全区单独保留。
- 不使用深色宣传横幅与渐变。首页「留白馆览」以白色描边卡片呈现真实馆内概况，突出空闲席位；三类状态完整且非负时显示状态分布条，不将其视为全馆容量或占用率。

## 页面与操作

- 首页采用已选定的 A「留白馆览」：三项馆内指标（空闲座位、正在使用、等待签到）直接展示，缺失值使用 `—`，真实零值显示 `0`；保留同步标记及刷新入口，展示真实当前预约及各区域概况。首页不再重复提供查找、布局和收藏快捷入口；馆内公告按需展开，保留原文段落、换行和列表边界并逐条呈现，不截断短公告；小屏和大字体改为纵向指标。
- 首页“各区域座位”默认展开，可手动收起或展开；收起时保留标题、日期、同步摘要和刷新入口，数据刷新不会重置用户选择。自动发现当天的场馆、楼层和区域并读取实际座位布局，逐区域显示总席数、各状态数量与状态分布。加载、失败和额外验证保留明确提示，未读数值不显示为零；部分刷新时新旧区域各自显示更新时间及旧数据标记，使用中、已预约、暂离计入已确认占用，未知与仅限现场单独列出。
- 点击区域卡片直接打开对应座位布局视图，显示区域名称、日期及地图，不先显示日期/场馆/楼层选择表单；返回即回首页。打开前重新校验服务器选项及实际布局，不以旧统计推算坐标，也不自动改到其他区域。
- 选座保留日期、场馆、区域和座位号；“时间、电源与靠窗”入口及其展开的筛选项位于“座位号（可选）”上方，默认收起。座位结果在常用手机宽度下每行展示两个白色卡片，相邻卡片按本行内容自然等高；大字体继续保留双列，通过紧凑字号与文字换行适配。仅当内容宽度小于 260dp 时改为单列。“可预约”与“不可预约”采用相同的小标签样式；可预约卡片与标签均可选择使用时间，整张卡片提供大触控区域，收藏保留独立的 48dp 操作区域。
- 切换场馆立即清空旧区域并显示独立加载状态，区域准备完成前禁用区域选择与查询；读取失败可只重试当前场馆的区域。刷新筛选会重新校验保留的场馆与区域，分页失败保留原有结果并重试失败页，取消请求或切换账号后不接收旧响应。
- “选座”顶部采用与其他页面一致的 `BUCEA / LIBRARY` 装饰文字、标题和标语“为专注，找一个喜欢的位置。”，保留刷新按钮，不显示返回按钮；固定并列的“自选座位”和“布局选座”标签页，与“我的”四段分类复用灰底、白色选中项的圆角分段样式，选中项使用主题色文字。两处标签栏常规高度统一为 44dp（内项 40dp、外侧留白 2dp），大字体时随文字自然增高。内容滚动时仍可切换，切换后保留各自的筛选、区域及滚动位置；刷新仅作用于当前标签页，两种模式的系统返回均回到首页。查询操作在展开所有筛选条件后仍保留底部安全区，避免被导航栏遮挡。
- 底部导航保留首页、选座、我的与设置的滚动位置和展开状态，包括选座内部两种模式的独立状态；切换账号或登录状态时重新建立页面状态，避免沿用其他身份的界面。离开账号页会关闭未完成的编辑面板，输入中的凭据只保存在内存。
- 地图保留真实坐标、拖动、双指缩放及适应区域，地图与列表使用显式分段切换。
- 地图区域加载失败时，重试继续读取刚才请求的区域；已显示的旧布局不改变重试目标。切换账号、日期、场馆或楼层后清除旧区域请求。
- 预约使用底部面板，先选择开始 / 结束时间，再核对日期、座位、账号和时段。时间框打开完整的服务器选项，避免平铺大量时间按钮。
- 我的图书馆使用四段分类：预约、收藏、常用、违约。我的预约移除重复的查找座位和布局选座入口，保留真实当前状态及 Wi-Fi 签到说明。预约时间线优先按日期与开始时间展示接下来的预约，结束或取消的记录独立放入历史预约；每项显示日期、时段、座位、位置、状态与详情，取消仍需确认。缺失日期的记录显示时间待确认，加载更多继续读取服务器分页并重新排序。
- 账号采用头像、两行账号信息与底部编辑面板，“当前使用”放在页面顶部账号摘要中。窄屏与大字体将修改、删除移至独立操作行，保留至少 48dp 触控区域。忙碌时禁用新增、编辑、删除及保存路径，备注修改与凭据更新继续分开处理。页面重建保留编辑目标和备注草稿，密码与新账号输入保持内存状态，重建后需重新输入。
- 设置分组呈现应用更新、主题色、登录偏好及关于 / 反馈；“官方网站”打开北京建筑大学图书馆官网 `https://lib.bucea.edu.cn/`，底部署名为 `BUCEA-LIBRARY-SEAT · 非官方客户端`。更新内容按需展开，上下箭头及无障碍状态同步反映展开结果，主题选择使用底部面板。页面与章节标题提供无障碍标题标记。
- QQ 交流群入口点按打开 QQ 入群页面，长按复制群号，未安装 QQ 时以 Toast 提示。
- 自动验证、更新、网络提示与空状态统一字体、圆角及按钮尺寸。
- 预约、取消预约、收藏和座位操作通过一次性 Toast 反馈结果；只有已确认成功的服务器结果显示成功，失败或不确定结果保留对应提示，查询刷新继续在页面展示进度。

## 布局选座状态

地图采用不透明的座位色块、白色座位号和状态短字，图例、列表徽标与座位详情保持一致。状态色独立于应用主题；切换奶龙黄等主题时，选中座位的主题色描边保留深色外框。各状态色与白字的对比度均不低于 4.5:1，放大后可同时读取座位号和状态，不仅依靠颜色区分。

| 当前状态 | 座位短字 | 色值 |
| --- | --- | --- |
| 空闲 | 空 | `#087F6D` |
| 使用中 | 用 | `#B33F32` |
| 已预约 | 约 | `#94600A` |
| 暂离 | 离 | `#754BA5` |
| 不可用 | 停 | `#586471` |
| 未知状态 | ? | `#626C79` |
| 仅限现场 | 现 | `#2756A4` |

当前状态与服务器是否允许预约分开呈现：使用中、已预约或暂离的座位允许预约其他时段时仍保留原有状态色。空闲描述不能覆盖服务器的禁用标志；仅限现场的座位不会提供线上预约入口。电源标记使用白色圆环与深色圆心，避免与主题色或座位状态混淆。真实坐标、空走道、拖动、双指缩放和适应区域继续由原始布局决定。

## 实现位置

`LibraryTheme.kt` 定义颜色、字体与形状；`LibraryComponents.kt` 提供共享页头、卡片、空态等组件；`LibraryScreens.kt` 组织首页、账号与设置；选座、地图及我的页面保留各自的独立文件。

`BusinessAlertDialog` 用于确认操作，`BusinessSelectionSheet` 用于选择与编辑。它们都计入现有业务交互状态，避免更新提示覆盖当前操作。选择面板正文可以收缩并滚动，底部操作保持独立，适配软键盘。

查询、预约、验证、账号和更新均通过原生数据层与 ViewModel 执行。界面规范以本文与原生组件实现为准。
