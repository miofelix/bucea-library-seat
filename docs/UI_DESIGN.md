# 留白界面

原生应用统一采用「留白」界面。简洁优先，通过排版、留白和少量主题色建立层次。

## 视觉规则

- 页面背景为中性的 `#FAFAFA`，正文 `#272729`，次要文字 `#707075`，分隔线 `#E7E7E9`。
- 主题色来自 `AppThemeColor` 与外观存储，默认建大紫 `#6C397F`，提供包含奶龙黄的六种颜色。主题切换同步桌面图标；奶龙黄使用亮黄底色、深色按钮文字和可读的深金色文本与选择控件。
- 页面横向留白 24dp，主要区域相隔 16–20dp；白色卡片使用 18–24dp 圆角、细描边与零阴影。
- 无衬线页面标题 26sp，组件标题 14–20sp，正文 12–15sp。主要按钮至少 48dp，圆角 12dp。
- 底部导航采用紧凑的白色圆角容器，20dp 图标配 10sp 标签，选中项使用浅主题色背景，单项触控高度至少 48dp；系统安全区单独保留。
- 不使用深色宣传横幅与渐变。首页「留白馆览」以白色描边卡片呈现真实馆内概况，突出空闲席位；三类状态完整且非负时显示状态分布条，不将其视为全馆容量或占用率。

## 页面与操作

- 首页采用已选定的 A「留白馆览」：三项馆内指标（空闲座位、正在使用、等待签到）直接展示，缺失值使用 `—`，真实零值显示 `0`；保留同步标记及刷新入口，展示真实当前预约及各区域概况。首页不再重复提供查找、布局和收藏快捷入口；公告按需展开，小屏和大字体改为纵向指标。
- 首页“各区域座位”默认展开，可手动收起或展开；收起时保留标题、日期、同步摘要和刷新入口，数据刷新不会重置用户选择。自动发现当天的场馆、楼层和区域并读取实际座位布局，逐区域显示总席数、各状态数量与状态分布。加载、失败和额外验证保留明确提示，未读数值不显示为零；部分刷新时新旧区域各自显示更新时间及旧数据标记，使用中、已预约、暂离计入已确认占用，未知与仅限现场单独列出。
- 点击区域卡片直接打开对应座位布局视图，显示区域名称、日期及地图，不先显示日期/场馆/楼层选择表单；返回即回首页。打开前重新校验服务器选项及实际布局，不以旧统计推算坐标，也不自动改到其他区域。
- 选座保留日期、场馆、区域和座位号；时间、电源与靠窗条件默认收起。座位结果在常用手机宽度下每行展示两个白色卡片，相邻卡片按本行内容自然等高；大字体继续保留双列，通过紧凑字号与文字换行适配。仅当内容宽度小于 260dp 时改为单列。“可预约”与“不可预约”采用相同的小标签样式；可预约卡片与标签均可选择使用时间，整张卡片提供大触控区域，收藏保留独立的 48dp 操作区域。
- 地图保留真实坐标、拖动、双指缩放及适应区域，地图与列表使用显式分段切换。
- 预约使用底部面板，先选择开始 / 结束时间，再核对日期、座位、账号和时段。时间框打开完整的服务器选项，避免平铺大量时间按钮。
- 我的图书馆使用四段分类：预约、收藏、常用、违约。我的预约移除重复的查找座位和布局选座入口，保留真实当前状态及 Wi-Fi 签到说明。预约时间线优先按日期与开始时间展示接下来的预约，结束或取消的记录独立放入历史预约；每项显示日期、时段、座位、位置、状态与详情，取消仍需确认。缺失日期的记录显示时间待确认，加载更多继续读取服务器分页并重新排序。
- 账号采用头像、紧凑的两行账号卡片与底部编辑面板，“当前使用”放在页面顶部账号摘要中。忙碌时禁用新增、编辑、删除及保存路径，备注修改与凭据更新继续分开处理。
- 设置分组呈现应用更新、主题色、登录偏好及关于 / 反馈。更新内容按需展开，主题选择使用底部面板。
- QQ 交流群入口点按打开 QQ 入群页面，长按复制群号，未安装 QQ 时以 Toast 提示。
- 自动验证、更新、网络提示与空状态统一字体、圆角及按钮尺寸。
- 预约、取消预约、收藏和座位操作通过一次性 Toast 反馈结果；只有已确认成功的服务器结果显示成功，失败或不确定结果保留对应提示，查询刷新继续在页面展示进度。

## 布局选座状态

地图采用不透明的座位色块、白色座位号和状态短字，图例、列表徽标与座位详情保持一致。状态色独立于应用主题；切换奶龙黄等主题时，选中座位的主题色描边保留深色外框。各状态色与白字的对比度均不低于 4.5:1，放大后可同时读取座位号和状态，不仅依靠颜色区分。

| 当前状态 | 座位短字 | 色值 |
| --- | --- | --- |
| 空闲 | 空 | `#087F6D` |
| 使用中 | 用 | `#B33F32` |
| 已预约 | 约 | `#94600A` |
| 暂离 | 离 | `#754BA5` |
| 不可用 | 停 | `#586471` |
| 未知状态 | ? | `#626C79` |
| 仅限现场 | 现 | `#2756A4` |

当前状态与服务器是否允许预约分开呈现：使用中、已预约或暂离的座位允许预约其他时段时仍保留原有状态色。空闲描述不能覆盖服务器的禁用标志；仅限现场的座位不会提供线上预约入口。电源标记使用白色圆环与深色圆心，避免与主题色或座位状态混淆。真实坐标、空走道、拖动、双指缩放和适应区域继续由原始布局决定。

## 实现位置

`LibraryTheme.kt` 定义颜色、字体与形状；`LibraryComponents.kt` 提供共享页头、卡片、空态等组件；`LibraryScreens.kt` 组织首页、账号与设置；选座、地图及我的页面保留各自的独立文件。

`BusinessAlertDialog` 用于确认操作，`BusinessSelectionSheet` 用于选择与编辑。它们都计入现有业务交互状态，避免更新提示覆盖当前操作。选择面板正文可以收缩并滚动，底部操作保持独立，适配软键盘。

查询、预约、验证、账号和更新均通过原生数据层与 ViewModel 执行。界面规范以本文与原生组件实现为准。
