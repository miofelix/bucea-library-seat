# 北建大图书馆选座

北京建筑大学图书馆的非官方 Android 客户端，让登录、选座和预约更方便。全部界面采用原生设计。

[下载测试版 v0.3.2-beta.1](https://github.com/miofelix/bucea-library-seat/releases/tag/v0.3.2-beta.1)

支持 Android 8.0 及以上。使用前请连接可访问图书馆的校园网；签到需要连接图书馆内部 Wi-Fi。

- 保存账号并自动识别验证码，下次恢复登录；支持多个账号及自动切换。
- 原生座位地图支持拖动、缩放和列表浏览，选择可用时段后确认预约。
- 查看预约及违约记录，收藏常用座位；不同颜色区分空闲、已预约、使用中和不可用状态。
- 快速筛选立即生效，仅筛选当前已加载的一页座位；其他结果可继续翻页。
- 账号备注可以独立修改，无需重新输入密码。

账号密码和登录信息加密保存在本机，验证码也在设备上识别。

修改图书馆密码当前未实现，点击入口会显示提示。
