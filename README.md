# 北建大图书馆选座

北京建筑大学图书馆的非官方 Android 客户端，让登录、选座和预约更方便。全部界面采用原生「留白」设计，以简洁、清爽和易用为优先。

[下载正式版 v1.0.0](https://github.com/miofelix/bucea-library-seat/releases/tag/v1.0.0)

多数现代手机选择 `arm64-v8a` 包（约 33.8 MB）；不确定架构时选择无后缀的通用包（约 55.5 MB）。同时提供 `armeabi-v7a`、`x86` 和 `x86_64`，各包均可独立安装。体积优化与取舍见 [APK 大小分析](docs/APK_SIZE.md)。

安装包今后统一使用 `BUCEA-Library-Seat-vx.x.x.apk`，本版通用包为 `BUCEA-Library-Seat-v1.0.0.apk`；分架构包增加 `-arm64-v8a` 等后缀。

支持 Android 8.0 及以上。使用前请连接可访问图书馆的校园网；签到需要连接图书馆内部 Wi-Fi。

访问失败后，从 Wi-Fi 设置返回应用会在空闲时自动重检连接。校园链路或图书馆服务器暂时不可用时，应用会显示“暂时无法访问图书馆”；连接校园网本身不保证服务器可达。

- 保存账号并自动识别验证码，下次恢复登录；支持多个账号及自动切换。
- 首页采用「留白馆览」，直接显示馆内概况，并自动读取各区域当天的座位占用情况，标明更新时间与同步状态；高级筛选按需展开，时段选择与账号编辑使用底部面板。
- “选座”页面通过顶部并列的“自选座位”和“布局选座”标签页切换，原生座位地图支持拖动、缩放和列表浏览，选择可用时段后确认预约。
- 查看预约及违约记录，在预约记录中确认取消预约；签到前可直接打开 Wi-Fi 设置，连接图书馆内部 Wi-Fi 后刷新状态。
- 在设置中切换建大紫、湖蓝、青绿、暖橙、玫瑰或奶龙黄六种主题颜色，默认建大紫（`#6C397F`）；选择即时生效、重启后保留，桌面图标随之变色。启用 Android 系统的单色“主题图标”时，图标颜色由壁纸配色决定。
- 长按座位卡片收藏或取消收藏，在“我的”页面直接为收藏或常用座位选择日期、时段并确认预约；常用座位由图书馆系统根据使用记录生成，手动收藏单独保存和展示。
- 座位结果采用一行四个的紧凑卡片，可预约为绿色边框，不可预约为红色边框，并独立显示当前使用状态。
- 自选座位在同一页面自动加载全部结果，中断后可继续；布局选座列表同样使用紧凑卡片，两处“仅看可用”筛选均即时生效。
- 账号备注可以独立修改，无需重新输入密码。

账号密码和登录信息加密保存在本机，验证码也在设备上识别。

修改图书馆密码当前未实现，点击入口会显示提示。

从 0.3.4 起支持应用内更新：打开“设置”，展开顶部“应用更新”后点击“手动检查更新”，确认后下载并由系统安装。检查更新无需连接校园网。旧版需先手动安装含更新模块的版本。构建与发布在开发机完成，树莓派只缓存 GitHub Release 成品；部署说明见 [更新服务](docs/UPDATES.md) 和 [树莓派接续文档](docs/RASPBERRY_PI_HANDOFF.md)。
