这是北京建筑大学图书馆的**非官方客户端**，为同学们提供更方便的选座与预约体验。

## 日常选座，少几步操作

- **先看馆内情况**：查看馆内概况与各区域座位占用情况。
- **按习惯找座位**：自选座位、布局选座自由切换，支持日期、时段、电源与靠窗筛选。
- **收藏常坐的位置**：长按座位收藏，下次直接选择日期与时段预约。
- **管理自己的预约**：查看预约与违约记录，取消预约，连接馆内 Wi-Fi 后签到。
- **登录更省心**：支持多账号、自动识别验证码与恢复登录。
- **选个喜欢的颜色**：原生简洁界面，提供建大紫等六种主题。

## 安装与使用

多数手机选择 **ARM64 版**；不确定时选择**通用版**。其他架构可在官网下载区选择，安装一个 APK 即可。

| 系统          | 支持情况                                                   |
| ------------- | ---------------------------------------------------------- |
| Android       | Android 8.0 及以上                                         |
| 鸿蒙          | 兼容 Android APK 的设备可尝试安装；HarmonyOS NEXT 暂不支持 |
| iPhone（iOS） | 暂不支持                                                   |

登录、查座与预约需连接**可访问图书馆服务器的校园网络**，签到需连接**图书馆内部 Wi-Fi**。若暂时无法访问，请检查网络或稍后重试。

账号密码和登录信息加密保存在本机，验证码也在设备上识别。
