# 北建大图书馆选座宣传片

成片为 `bucea-library-promo-landscape.mp4`：45 秒、1920 × 1080、60fps，H.264 / AAC 立体声。成片已随源码入库，打开 `preview.html` 可直接播放，`cover.png` 是配套封面。

以项目真实 Android 界面为基础，使用品牌紫与白底、悬浮设备、组件放大、动态数字、功能卡片、六色图标和 QR 下载页。设备采用通用示意边框，产品支持 Android 8.0+。保留非官方客户端与网络使用说明。姓名和预约账号已替换为演示文字，状态栏、手势栏已裁切；画面内数据仅用于演示。

音乐为专门创作的 90 BPM 轻松器乐，包含钢琴、电钢、颤音琴、暖音色及轻节奏，详见 [music/README.md](music/README.md)。

## 重新生成

需要 macOS（AppKit / CoreText / AVFoundation / CoreImage）、Swift 编译器、Python 3 和 FFmpeg。无需 FFmpeg 的 `drawtext`，文字与全部动画由原生渲染器生成。

```sh
bash promo/create_promo.sh
```

`assets/` 保存已清理的界面素材；当本机存在原始验收截图时，渲染器会重新裁切并清理它们。主题图标来自项目官方 SVG 与 `AppThemeColor.kt` 配色。视频、音频中间产物写入已忽略的 `.render/`。
