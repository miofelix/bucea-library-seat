# 北建大图书馆选座图标

采用选定的「书页折椅」方案：展开的书页自然折叠成座椅，以不对称的曲线连接阅读与选座。纯色设计，不使用渐变、阴影或装饰线。

| 颜色 | 色值 | 用途 |
| --- | --- | --- |
| 北建大紫 | `#6C397F` | 底色 |
| 白色 | `#FFFFFF` | 左页与座面 |
| 浅紫 | `#EADDF2` | 右页与折角 |

主紫色取自[北建大官网样式](https://www.bucea.edu.cn/gbcss/style.css)，[首页样式](https://www.bucea.edu.cn/gbcss/index.css)也使用同一色值。

- `bucea-library-seat-icon.svg`：完整图标，1024 × 1024，圆角透明。
- `bucea-library-seat-icon.png`：从 SVG 渲染的 1024 × 1024 PNG。

SVG 由五条命名路径组成，`viewBox` 为 `0 0 256 256`，可编辑、可无损缩放，不依赖字体或外部图片。

Android 使用相同路径制作原生 VectorDrawable，提供自适应图标与 Android 13 单色主题图标。前景保持在 108dp 画布的中央安全区域，支持圆形及圆角方形裁切。应用名称为“北建大图书馆选座”。

桌面图标跟随应用内主题色切换，共有建大紫 `#6C397F`、湖蓝 `#315DA8`、青绿 `#28766C`、暖橙 `#A85A20`、玫瑰 `#AC4567` 和奶龙黄 `#FFCE32` 六种底色。奶龙黄使用深棕色书页与座面，保持清晰对比；其余图标保留白色书页与同色系浅色折角。

应用内奶龙黄将品牌色与阅读色分开：`#FFCE32` 用于色块、图标和强调背景，背景上的文字为 `#3C2B06`；`#735300` 用于默认文字按钮、描边按钮、单选控件和浅色卡片内的小字。暖橙的小字使用略深的 `#9F551E`。六套主题的填充按钮、文字按钮及浅色卡片文字均以至少 4.5:1 的对比度验证。

每种颜色由独立 launcher alias 和图标资源提供，全部指向同一个 `MainActivity`；切换时保持真实 Activity 启用且不结束应用进程。Android 13 及以上通过批量操作原子切换，较早系统先启用新入口再关闭旧入口。应用保存颜色并在启动时同步，桌面刷新速度由启动器决定；启用 Android 的单色“主题图标”时，系统仍按壁纸配色绘制共享轮廓。
