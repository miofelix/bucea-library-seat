反馈问题与建议
这是学校官方应用吗？+

这是为北京建筑大学同学独立开发的非官方 Android 客户端。座位预约与使用遵循图书馆现有规则，应用不代表学校或图书馆。

需要校园网吗？为什么有时连不上？+

图书馆功能需要连接可访问图书馆服务器的校园网络，签到需要连接图书馆内部 Wi-Fi。从 Wi-Fi 设置返回应用后，会在空闲时重新检测。校园链路或图书馆服务器暂时不可用时，也会影响访问。

支持 iPhone 吗？安装包该怎么选？+

目前提供 Android 版本，支持 Android 8.0 及以上。多数现代手机选择 ARM64 版；不确定架构时选择通用版。其他架构的独立安装包可以在 GitHub Releases 下载。

账号和密码会如何保存？+

账号密码与登录信息加密保存在本机，验证码在设备上识别。登录、查询与预约仍需与图书馆服务器通信。可以在账号管理中删除本机保存的账号。

以后怎么更新？+

打开「设置 → 应用更新 → 手动检查更新」，确认后下载并交给 Android 系统安装。检查更新无需校园网，也可以从 GitHub Releases 下载新版覆盖安装。

如何反馈问题或加入交流群？+

欢迎在 GitHub Issues 留下问题与建议，也可以加入 QQ 交流群 ，和同学们分享使用体验。
